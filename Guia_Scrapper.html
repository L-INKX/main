3.1 — Corrigir clickReviewsTab

Ctrl+F → procure async clickReviewsTab() { e substitua todo o bloco por:

javascript
  async clickReviewsTab() {
    const spinner = display.startSpinner('Opening reviews tab...');
    await utils.sleep(3000);

    const clicked = await this.page.evaluate(() => {
        let el = document.querySelector('button[aria-label*="Reviews"], button[aria-label*="Avaliações"]');
        if (el) { el.click(); return 'aria-label'; }
        const tabs = Array.from(document.querySelectorAll('button[role="tab"]'));
        el = tabs.find(t => /Reviews|Avaliaç/i.test(t.textContent || ''));
        if (el) { el.click(); return 'tab-text'; }
        const buttons = Array.from(document.querySelectorAll('button'));
        el = buttons.find(b => /Reviews?\b|Avaliaç/i.test((b.textContent || '').trim()));
        if (el) { el.click(); return 'button-text'; }
        return null;
    });

    if (!clicked) {
        throw new Error('Reviews tab button not found on page');
    }

    await utils.sleep(2500);
    display.succeedSpinner(`Reviews tab opened (via ${clicked})`);
    this.logger.info('Reviews tab clicked');
  }

3.2 — Corrigir launchBrowser

Procure async launchBrowser() { e substitua por:

javascript
  async launchBrowser() {
    const spinner = display.startSpinner('Launching browser...');
    this.browser = await puppeteer.connect({
      browserURL: 'http://127.0.0.1:9222',
      defaultViewport: null
    });
    const pages = await this.browser.pages();
    this.page = pages.length > 0 ? pages[0] : await this.browser.newPage();
    if (this.config.blockResources) {
      await this.page.setRequestInterception(true);
      this.page.on('request', (req) => {
        const type = req.resourceType();
        if (['image', 'font', 'media'].includes(type)) {
          req.abort();
        } else {
          req.continue();
        }
      });
    }
    display.succeedSpinner('Browser connected successfully');
    this.logger.info('Connected to existing Chrome instance');
  }

FASE 8Gerar o TXT final (script tudo-em-um)

Cole este comando uma vez no PowerShell. Ele renomeia as fotos e gera o TXT final:

powershell
# ============================================
# SCRIPT TUDO-EM-UM
# ============================================
$N = 10  # numero de avaliacoes no TXT

$latest = Get-ChildItem data | Sort-Object LastWriteTime -Descending | Select-Object -First 1 -ExpandProperty Name
$runDir = "data\$latest"
$reviews = Get-Content "$runDir\reviews.json" -Raw -Encoding UTF8 | ConvertFrom-Json

$origem  = "$runDir\images\profiles"
$destino = "$runDir\images\perfis-nomeados"
New-Item -ItemType Directory -Path $destino -Force | Out-Null

$copiadas = 0
foreach ($r in $reviews) {
    if (-not $r.profilePictureLocal) { continue }
    if (-not (Test-Path $r.profilePictureLocal)) { continue }
    $nome = ($r.name -replace '[\\/:*?"<>|]', '_').Trim()
    $novoNome = ("{0:D2} - {1}.jpg" -f $r.rating, $nome)
    Copy-Item -Path $r.profilePictureLocal -Destination (Join-Path $destino $novoNome) -Force
    $copiadas++
}

$top = $reviews | Select-Object -First $N
$txt = "$runDir\avaliacoes-final.txt"
$linhas = @()
foreach ($r in $top) {
    $linhas += "Foto do cliente = $($r.profilePicture)"
    $linhas += "Nome do Cliente: $($r.name)"
    $linhas += "Avaliação do cliente: $($r.text)"
    $linhas += "----------"
}
$linhas | Out-File -FilePath $txt -Encoding UTF8

Write-Host ""
Write-Host "============================================"
Write-Host "  TUDO PRONTO"
Write-Host "============================================"
Write-Host "Pasta:            $runDir"
Write-Host "Fotos nomeadas:   $destino ($copiadas arquivos)"
Write-Host "TXT final:        $txt ($($top.Count) avaliacoes)"
Write-Host "============================================"

Resultado:

  • Pasta perfis-nomeados/ com fotos renomeadas para [rating] - [Nome].jpg
  • Arquivo avaliacoes-final.txt no formato pedido

💡 Dicas finais

  • A pasta data\ acumula um subdiretório por execução. Para limpar resultados antigos: Remove-Item -Recurse -Force .\data
  • O perfil chrome-profile\ guarda seu login. Se o Google voltar a bloquear, apague e faça login de novo.
  • Se a pausa de 3 min não bastar, aumente 180000 (3 min) para 300000 (5 min) no navigateToUrl.
  • Para pegar mais avaliações, aumente maxScrolls no config.yaml (ex.: 500).
  • Para mudar a quantidade no TXT final, altere $N = 10 no script tudo-em-um.
